# 🤖 Hoshizune Discord Bot

Многофункциональный Discord бот на TypeScript с поддержкой выдачи ролей по эмодзи реакциям.

## ✨ Функции

- 🎯 **Автоматическая выдача ролей новым участникам** (`/autorole`)
- 😊 **Выдача ролей по эмодзи реакциям** (`/reaction-roles`) - НОВОЕ!
- 👤 **Профиль пользователя** (`/profile`)
- 🖼️ **Информация об аватаре** (`/avatar`)
- 📊 **Статус бота** (`/ping`, `/about`)
- 🐱 **Рандомные кошечки** (`/nekos`)

## 🚀 Быстрый старт

## 🎮 Использование команды `/reaction-roles`

1. Выполни `/reaction-roles channel_id:<ID канала>`
2. Бот создаст (или обновит) сообщение с маппингом `эмодзи - роль` в указанном канале
3. В канале, где запущена команда, бот отправит панель с кнопками ролей
4. Нажми нужную роль -> откроется модалка, введи эмодзи
5. После сохранения бот сразу редактирует сообщение и обновляет реакции
6. Пользователь ставит реакцию на сообщение бота -> получает роль; убирает реакцию -> роль снимается

- PostgreSQL

docker compose up --build

## 📋 Конфигурация

Создай `.env` файл:
```env
DISCORD_APPLICATION_ID=твой_id
DISCORD_BOT_TOKEN=твой_токен
DATABASE_URL=file:./prisma/dev.db
```

`DATABASE_URL` указывает на локальный SQLite файл (создается автоматически)

## 🗄️ База данных

Проект использует **SQLite** с **Prisma ORM**.

Преимущества SQLite:
- ✅ Встроена в Node.js - нет установок
- ✅ Файловая БД - нет контейнеров
- ✅ Совершенно бесплатна
- ✅ Идеальна для разработки и небольших проектов

Файл БД: `prisma/dev.db` (создается автоматически)

Модели:
- `Guild` - настройки гильдии
- `ReactionRoleMessage` - маппинг эмодзи → роли

Миграции применяются автоматически при запуске `yarn deploy`.

## 🐛 Решение проблем

```bash
# SQLite база заблокирована
# Просто перезапусти бота:
yarn dev

# Сброс БД (удалит все данные!)
npx prisma migrate reset

# Просмотр БД (GUI)
npx prisma studio

# Проверить логи
yarn dev  # всё будет видно в консоли
```
