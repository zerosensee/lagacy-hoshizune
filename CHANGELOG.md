# Список изменений

## Добавленные возможности

1. Добавлен скрипт для запуска всего проекта в один клик через Docker.
2. Создана конфигурация для объединения базы данных и бота в единый стек.
3. Добавлен скрипт `refresh-commands.bat` для быстрой перерегистрации команд в Discord.
4. Добавлена комплексная система статистики сервера (участники, онлайн-статусы, голосовые каналы, активность чатов).
5. Реализована команда `/stats` для настройки ежедневных отчетов и ручных запросов за период.
6. Внедрена автоматическая ежедневная рассылка статистики в выбранный канал.

## Исправления

1. Исправлена структура Prisma-схемы: удалены некорректные импорты и настроена поддержка разделения файлов через функцию prismaSchemaFolder.
2. Исправлены ошибки типизации TypeScript в обработчиках реакций и командах.
3. Настроена выделенная внутренняя сеть Docker для надежного общения между контейнером бота и базой данных.
4. Устранено дублирование определений моделей в схеме базы данных, вызывавшее конфликт при сборке.
5. Исправлены ошибки типизации TypeScript в команде настройки ролей по реакциям, связанные с обработкой потенциально отсутствующих данных о сервере.
6. Устранены предупреждения о депрекации и исправлены ошибки времени выполнения при получении параметров команды.
7. Полностью удалено использование устаревшего параметра `ephemeral` во всех частях кода команды.
8. Исправлена логика автоматической выдачи и снятия ролей по реакциям: устранено несоответствие идентификаторов сервера в базе данных.
9. Обновлены интенты бота для поддержки сбора статистики сообщений и статусов пользователей.
10. Добавлено отображение количества офлайн-пользователей в отчеты статистики.
11. Обновлено визуальное оформление отчетов статистики с использованием новых кастомных эмодзи.
12. Снято ограничение на максимальное количество дней при запросе статистики.

## Удаления

1. Удалена команда `avatar`.
