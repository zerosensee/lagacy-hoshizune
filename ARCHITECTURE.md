## 4️⃣ Структура БД

```sql
┌─────────────────────────────────────────┐
│ reaction_role_messages                  │
├─────────────────────────────────────────┤
│ id (UUID) PRIMARY KEY                   │
│ guild_id (TEXT) → guilds.id             │ ← Foreign Key
│ channel_id (TEXT)                       │
│ message_id (TEXT)                       │
│ mappings (JSONB)                        │ ← { "😊": "roleId1", "😂": "roleId2" }
│ created_at (TIMESTAMP)                  │
│ updated_at (TIMESTAMP)                  │
│                                         │
│ UNIQUE(guild_id, channel_id, message_id)│
└─────────────────────────────────────────┘
```

Пример `mappings`:
```json
{
  "😊": "1234567890123456789",
  "😂": "9876543210987654321",
  "❤️": "5555555555555555555"
}
```

## 6️⃣ Команды для управления

```bash
# Запуск контейнера
docker-compose -f docker-compose.test.yml up -d

# Остановка контейнера
docker-compose -f docker-compose.test.yml down

# Просмотр логов
docker logs -f hoshizune-postgres

# Перезагрузка контейнера
docker-compose -f docker-compose.test.yml restart

# Подключение к БД напрямую
docker exec -it hoshizune-postgres psql -U postgres -d hoshizune_test
```

## 7️⃣ Решение проблем

| Проблема | Решение |
|----------|---------|
| "Cannot connect to database" | `docker-compose -f docker-compose.test.yml restart` |
| "Port 5432 already in use" | Измени порт в docker-compose.test.yml на 5433 |
| "Command not found: docker" | Переустанови Docker Desktop |
| "Yarn not found" | `npm install -g yarn` |
| "Token is invalid" | Проверь токен в .env файле |
